# DSA-Unit-3-Linked-List
# Movie Ticket Management Using Linked List

## Problem Statement
Design and implement a Movie Ticket Management System using a
Singly Linked List in C++. Store ticket number and movie name
and display the movie ticket records.

## Algorithm
1. Create a node containing ticket number and movie name.
2. Allocate memory dynamically for each node.
3. Insert nodes at the end of the linked list.
4. Traverse the linked list using a pointer.
5. Display all movie ticket records.

## Explanation
A Singly Linked List is used to store movie ticket records dynamically.
Each node contains ticket number, movie name and a pointer to the next node.

## Sample Input
101 Pushpa
102 Dangal
103 Avatar

## Sample Output
Movie Ticket Records:
Ticket No: 101 Movie: Pushpa
Ticket No: 102 Movie: Dangal
Ticket No: 103 Movie: Avatar
